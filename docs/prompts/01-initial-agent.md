# Initial agent build

**Intent:** Create a real Windows AI agent in the existing project, not a design-only chatbot.

**Requirements:** Provider-neutral local/cloud model interface; plan/action/permission/tool/observe/verify/replan loop; filesystem/PowerShell/Python/browser/Windows tools; SQLite memory; CLI; setup/start scripts; tests; exact environment inspection.

**Introduced:** The shared core, registry, permissions, verifier, memory databases, Windows scripts, and end-to-end tool workflows.

**Superseded by:** Later intent routing, final-state verification, multimodal state, and model capability routing strengthened the original loop without replacing it.
