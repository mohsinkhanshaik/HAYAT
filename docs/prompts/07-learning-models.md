# Multi-model intelligence and learning

**Intent:** Deepen neural retrieval, capability routing, adaptive teaching, permanent evaluation, and controlled future fine-tuning.

**Requirements:** Local embedding registry/cache/hybrid ranking; measured model profiles/fallback/warmth; mastery/prerequisite graph/active recall/labs; golden evaluations; redacted verified split datasets; no automatic training.

**Introduced:** Ollama MiniLM retrieval, adaptive router/outcome evidence, learning database, evaluation manager, and gated training pipeline.

**Current status:** Fine-tuning remains intentionally disabled; hashed-semantic retrieval remains an offline fallback.
