# Advanced multimodal zero-cost operating layer

**Intent:** Unite text, voice, screen, image, camera, browser, files, clipboard, terminal, internet, memory, tools, learning, and automation through one grounded agent with $0 mandatory API cost.

**Requirements:** Fail-closed cost policy, camera privacy/change detection, local OCR when available, multi-monitor/world state, ephemeral clipboard, resource routing, incident/observability, durable jobs/events, safe labs, hardware/performance evidence.

**Introduced:** Cost policy, OpenCV camera manager, Win32 displays, clipboard redaction boundary, resource observer/router, event bus, checkpoints, incident snapshots, and lab simulations.

**Current limitation:** Local Tesseract was not installable without expanding system scope, so OCR is explicitly unavailable rather than simulated.
