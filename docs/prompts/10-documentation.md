# Full documentation requirement

**Intent:** Let a zero-knowledge user operate safely, then progressively understand the architecture at developer depth.

**Requirements:** README quick starts/status, complete command/config/data/safety/troubleshooting/reference guides, beginner/intermediate/advanced layering, prompt/history provenance, examples/glossary/FAQ/limitations, actual code/commit evidence, and documentation drift tests.

**Introduced:** The current README and linked documentation system.

**Completion rule:** Future user-visible changes require code, tests, and updated docs; undocumented behavior is not complete.
