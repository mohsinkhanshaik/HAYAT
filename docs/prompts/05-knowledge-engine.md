# Claim/evidence knowledge engine

**Intent:** Turn browsing results into reusable, updateable, evidence-backed knowledge.

**Requirements:** Claim-source graphs, exact excerpts/hashes, source independence, contradiction/freshness handling, monitored sources, temporal history, cache reuse, citation failure closed.

**Introduced:** Structured claims/evidence/entities/relationships, query/source caches, performance records, knowledge explanations and exports.

**Current status:** Doctor verifies the live database; unsupported or unretrieved citations are not accepted as evidence.
