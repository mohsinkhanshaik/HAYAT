# Glossary

- **AI:** software that performs tasks associated with reasoning, language, perception, or learning.
- **Agent:** a system that turns a goal into actions, observations, verification, and a result.
- **API:** a defined way for software components to communicate.
- **Approval:** an explicit human decision allowing one scoped `ASK` action.
- **Artifact:** a report, screenshot, script, or other task output.
- **Benchmark:** a repeatable measurement used to compare behavior, quality, or speed.
- **Browser DOM:** a structured tree of webpage elements; more reliable than pixel guessing.
- **Cache:** saved data reused to reduce repeated work while respecting freshness.
- **Checkpoint:** durable state recorded after an action so progress can be inspected/recovered.
- **Citation:** a retrieved source URL and evidence supporting a claim.
- **CLI:** the text command-line interface.
- **Cloud model:** a model run by an external service; blocked by default policy here.
- **Cold model:** installed/available but not currently loaded, so first use is slower.
- **Context:** relevant instructions, state, history, memory, and evidence given to a model.
- **CUDA:** NVIDIA's GPU computing platform.
- **Docker:** a platform for isolated application containers.
- **Embedding:** a numeric representation of text used to compare semantic meaning.
- **Event bus:** a local durable stream of typed system events.
- **Fine-tuning:** updating model weights with a curated dataset.
- **Git:** version-control software that records reversible code history.
- **Git commit:** a named snapshot of selected tracked changes.
- **GPU:** a processor suited to parallel graphics/AI operations.
- **Hallucination:** an unsupported claim presented as if true.
- **Hash:** a repeatable fingerprint used for integrity/deduplication, such as SHA-256.
- **Hybrid retrieval:** merging lexical, embedding, entity, project, recency, and quality signals.
- **Intent:** the system's classification of what the user means/wants.
- **JSON:** a structured text data format used for tool inputs/results.
- **Kubernetes:** a system for deploying and managing containers across machines.
- **Latency:** elapsed time between request and result (or stages within it).
- **LLM:** a large language model that predicts/generates text.
- **LoRA:** a parameter-efficient fine-tuning method using small adapters.
- **Local model:** a model running on the user's machine or local network endpoint.
- **Memory:** persisted facts, tasks, procedures, or learning state retrieved in later work.
- **Mode:** a composable policy that changes speed/depth/privacy/role priorities.
- **NCCL:** NVIDIA's library for GPU collective communication.
- **Neural retrieval:** semantic retrieval using model-produced embeddings.
- **OCR:** optical character recognition: extracting text from images.
- **Ollama:** a local model server and model manager.
- **Parameter:** a learned numeric value in a neural network; model size often counts them.
- **Permission:** an `ALLOW`, `ASK`, or `DENY` rule for a tool category.
- **Playwright:** browser automation using pages, DOM, and accessibility structure.
- **Prompt:** text/instructions/context sent to a model.
- **Prompt injection:** untrusted content attempting to override user/system policy.
- **QLoRA:** LoRA training applied to a quantized base model to reduce resource use.
- **Quantization:** storing model values at lower precision to reduce memory/disk, sometimes affecting quality.
- **RAG:** retrieval-augmented generation: adding retrieved evidence to model context.
- **Reranker:** a second scoring stage that reorders retrieved candidates.
- **SFT:** supervised fine-tuning on input/desired-output examples.
- **SQLite:** an embedded database stored as a local file.
- **STT:** speech-to-text transcription.
- **TTS:** text-to-speech output.
- **Token:** a chunk of text processed/generated by a model.
- **Tool:** a typed, permissioned handler for filesystem/browser/Windows/etc. work.
- **VAD:** voice activity detection for speech start/end/silence.
- **Vector:** an ordered numeric list; embeddings are vectors.
- **Verification:** checking observed evidence against expected and final success criteria.
- **VRAM:** memory on the GPU used by models/graphics.
- **Warm model:** a model already loaded and ready for lower-latency use.
- **World state:** authoritative live state from sensors, APIs, tools, and verified memory.
